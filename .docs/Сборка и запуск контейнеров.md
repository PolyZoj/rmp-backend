## Важно!
Если перезапускать swarm, то для master и replica нужно запустить `./cleanup-sentinels.sh`

Для запуска
```
docker swarm init #Только первый раз
docker stack deploy -c .\docker-compose.yml backend
# или
docker stack deploy -c .\docker-compose.dev.yml backend
```

Для выхода из swarm (удаляет контейнеры)
```
docker swarm leave --force
```
